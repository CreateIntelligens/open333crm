## ADDED Requirements

### Requirement: 分群條件依群發建立者的可見範圍判斷

分群群發的條件 MUST 以群發建立者的渠道可見範圍判斷：建立者有 `channel.view_all`（總店）時以所有渠道的身分判斷，否則只以建立者看得到的渠道的身分判斷。收件人 MUST 仍只限群發渠道的身分。送出（立即發送、排程、附券廣播）MUST 依建立者判斷，不依按下送出的成員；建立者的權限 MUST 比照路由的權限檢查（角色權限與方案天花板的交集），建立者不存在時 MUST 視為沒有可見渠道。預估人數與批次發放建立時的人數檢查 MUST 以操作的成員的可見範圍判斷。

#### Scenario: 分店建立的分群群發只以可見渠道判斷條件

- **WHEN** 分店成員只看得到 WebChat 渠道 CH-A，聯絡人 C 在 CH-A 有身分、在其他分店的 FB 渠道也有身分，分店成員以分群「有 FB 帳號」對 CH-A 預估並建立群發後送出
- **THEN** 預估的 `matched` 是 0
- **AND** 送出回 400 `BROADCAST_NO_RECIPIENTS`，沒有送出任何訊息

#### Scenario: 總店建立的分群群發以所有渠道判斷條件

- **WHEN** 總店成員以同樣的分群對 CH-A 預估並建立群發，由分店成員按下送出
- **THEN** 預估的 `matched` 至少是 1
- **AND** 送出成功，C 收到訊息
