# member-binding

將對話渠道的聯絡人綁定至商家會員身分，含設定驅動的對外 API 介面。

## ADDED Requirements

### Requirement: 綁定須經平台身分驗證

系統 SHALL 在建立綁定前，先經平台驗證取得可信的使用者身分。

#### Scenario: 顧客完成綁定

- **GIVEN** 顧客從觸發入口進入綁定頁
- **WHEN** 完成平台身分驗證
- **THEN** 系統取得該使用者的平台識別
- **AND** 以此識別對應到系統中的聯絡人

#### Scenario: 身分驗證失敗

- **GIVEN** 平台身分驗證未通過
- **WHEN** 顧客嘗試綁定
- **THEN** 系統拒絕綁定並說明原因
- **AND** 不建立任何對應紀錄

### Requirement: 綁定結果保存商家會員識別

綁定成功時，系統 SHALL 將商家會員識別與聯絡人建立對應，供後續查詢使用。

#### Scenario: 綁定成功後可查得會員識別

- **GIVEN** 顧客完成綁定
- **WHEN** 系統查詢該聯絡人
- **THEN** 可取得其對應的商家會員識別

#### Scenario: 同一聯絡人重複綁定

- **GIVEN** 聯絡人已有綁定紀錄
- **WHEN** 再次完成綁定流程
- **THEN** 更新為最新的對應，不產生重複紀錄

### Requirement: 綁定成功可自動貼標

商家設定綁定貼標時，系統 SHALL 於綁定成功後為該聯絡人貼上指定標籤。

#### Scenario: 綁定後標籤生效

- **GIVEN** 商家設定了綁定成功貼標
- **WHEN** 顧客完成綁定
- **THEN** 該聯絡人被貼上指定標籤
- **AND** 該標籤可用於後續分眾

### Requirement: 對外會員 API 以設定描述，不寫死於程式

系統 SHALL 允許以設定描述外部會員 API 的呼叫方式與欄位對應，使多數對接無須修改程式。

#### Scenario: 以設定完成對接

- **GIVEN** 商家提供會員查詢 API 的端點、認證方式與回應格式
- **WHEN** 管理者於後台填寫對應設定
- **THEN** 綁定流程能依該設定呼叫外部 API
- **AND** 依欄位對應取出會員識別

#### Scenario: 外部 API 呼叫失敗

- **GIVEN** 外部會員 API 無回應或回傳錯誤
- **WHEN** 顧客嘗試綁定
- **THEN** 顧客看到可理解的失敗訊息
- **AND** 系統記錄錯誤供排查
- **AND** 不建立不完整的綁定紀錄

#### Scenario: 外部查無此會員

- **GIVEN** 外部 API 回報查無此會員
- **WHEN** 顧客嘗試綁定
- **THEN** 系統告知查無會員，而非泛稱失敗

### Requirement: 綁定入口可由多種方式觸發

系統 SHALL 支援從圖文選單、關鍵字回覆與卡片訊息按鈕進入綁定流程。

#### Scenario: 由圖文選單進入綁定

- **GIVEN** 商家在圖文選單設定了綁定入口
- **WHEN** 顧客點選該區塊
- **THEN** 進入綁定頁

#### Scenario: 由關鍵字觸發綁定

- **GIVEN** 商家設定了觸發綁定的關鍵字
- **WHEN** 顧客傳送該關鍵字
- **THEN** 系統回覆帶有綁定入口的訊息
