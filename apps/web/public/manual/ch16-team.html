CHAPTER 16 · 分析與管理

人員、角色與權限

幫同事開帳號、決定每個人能做哪些事、看得到哪些渠道；也教你修改自己的密碼，以及設定用指紋或臉部辨識登入。

1 這頁能做什麼

這一章的功能都在左側選單「分析與管理 → 設定」底下。「人員管理」和「角色與權限」通常是管理員在用；「一般設定」和「Passkey 登入」則是每個人管理自己帳號的地方，所有人都用得到。

三個預設角色管理員、主管、客服各能做什麼 新增人員幫新同事開帳號、選角色、選渠道 編輯人員換角色、重設密碼、調整可用渠道 停用與刪除同事離職時怎麼處理 角色與權限調整角色權限、建立自訂角色 修改密碼改自己的登入密碼 Passkey 登入用指紋、臉部辨識登入

2 三個預設角色能做什麼

每位成員都會被指派一個「角色」，角色決定他能做哪些事。系統內建三個角色，畫面上顯示英文名稱：Admin（管理員）、Supervisor（主管）、Agent（客服）。下表是系統預設的分工，你的公司可能已經調整過，實際以「角色與權限」頁的勾選為準（見第 7 節）。

預設的客服權限其實不小：可以刪除工單、合併聯絡人、刪除全公司共用的標籤。如果你希望客服只做回覆與處理工單，請管理員到「角色與權限」把 Agent 的這幾項取消勾選。
ℹ️
人員管理頁下方的角色說明（例如「Agent：只能看自己負責的對話/案件」）是舊的寫法，和目前的實際分工不同，請以這張表和「角色與權限」頁為準。

3 人員列表

「設定 → 人員管理」列出公司裡所有啟用中的成員，看得到每個人的角色和手上的工單數。

畫面上的欄位說明
全部／ADMIN／SUPERVISOR／AGENT依角色篩選，數字是人數。被指派自訂角色的人，會被算進他原本的內建角色那一類
姓名姓名與登入用的電子信箱
角色目前的角色；自訂角色會顯示自訂的名稱
開啟案件指派給他的工單數。目前已結案的工單也算在內，所以數字可能比實際處理中的多

ℹ️
如果列表顯示「沒有符合條件的人員」，通常不是公司沒人，而是你的帳號沒有「檢視成員」權限，或資料暫時讀取失敗。請重新整理，仍然一樣就找管理員確認。

4 新增人員

有新同事加入時，在這裡幫他開帳號。管理員與主管都可以新增人員。

  1. 到「設定 → 人員管理」，按右上「新增人員」。
  2. 填「姓名」和「電子信箱」。電子信箱就是他的登入帳號。
  3. 在「角色」選一個角色（預設是 Agent）。
  4. 填「初始密碼」，至少 8 個字。建立後請把密碼私下告訴他，並請他登入後到「一般設定」改成自己的密碼。
  5. 在「看得到哪些渠道」勾選他負責的渠道（預設全部勾選）。
  6. 確認無誤後按「建立」。

「看得到哪些渠道」是什麼意思

如果你的公司有好幾個 LINE 官方帳號、粉專（例如總店與各分店各一個），可以用這個清單讓同事只看到自己負責的渠道。勾了的渠道，他才看得到該渠道的對話與工單；沒勾的就完全看不到。

  • 例：台中分店的客服只勾「台中店 LINE」，他就不會看到台北店客人的訊息。
  • 角色若有「檢視所有渠道（總店）」權限（預設只有管理員有），不受這個清單限制，一律看得到全部。
  • 如果全部取消勾選，畫面會出現「只有總店…看得到」的提示，意思是：這位同事什麼渠道都看不到。
⚠️
電子信箱請一律用小寫輸入。系統目前會照你打的大小寫存起來，但登入時大小寫要完全一致，例如你輸入 Amy@Example.com，同事用小寫登入會失敗。
ℹ️
如果跳出「已達方案客服人數上限，請升級方案」，代表啟用中的人數已經用完方案額度。可以先刪除不再使用的帳號，或到「方案／帳務」了解升級方式。一個電子信箱在整個系統只能用一次，跳出「Email 已被使用」時請換一個。

5 編輯人員

同事換職務、忘記密碼、或負責的渠道改變時，在這裡調整。

  1. 在人員列表找到那位同事，按他那列最右邊的「編輯」。
  2. 要換角色：在「角色」下拉選新的角色。
  3. 同事忘記密碼：在「重設密碼」填一組新密碼（至少 8 個字）。不改密碼就留空。
  4. 調整他負責的渠道：在「可使用的渠道」勾選或取消。
  5. 按「儲存」。
ℹ️
為了避免有人越權，系統有幾道保護：不能把別人改成比自己權限更高的角色；不能把自己改成沒辦法管理角色的角色；公司最後一位管理員不能被停用或刪除。
ℹ️
主管也可以編輯人員。只改密碼或渠道、沒動「角色」時，系統不會重新檢查角色，可以直接儲存；要把別人換成比自己權限更高的角色，才會被擋下來。

6 停用與刪除人員

同事離職或不再使用帳號時，在「編輯」對話框左下角有兩個按鈕。只有管理員看得到。

按鈕結果
停用他無法登入，電子信箱仍被這個帳號佔著，不能再拿來開新帳號。之後可以重新啟用
刪除永久刪除帳號、釋放電子信箱（可以再用同一個信箱開帳號）。他經手的對話與工單會解除指派，歷史紀錄保留。無法復原

停用同事

  1. 在人員列表那位同事那列按「編輯」。
  2. 按左下角「停用」，確認視窗按「確定」。
  3. 他會從上方的人員列表移到頁面下方的「已停用的人員」區塊。

重新啟用

同事回來上班、或停用錯人時，可以把帳號找回來。

  1. 到「設定 → 人員管理」，往下捲到「已停用的人員」區塊（有停用的人才會出現）。
  2. 在那位同事那列按「重新啟用」。
  3. 他會回到上方的人員列表，用原本的帳號密碼登入，角色維持停用前的設定。
ℹ️
  • 同事只是暫時不用（例如請長假），用「停用」就好，之後隨時能重新啟用。
  • 確定離職、想把電子信箱釋放出來另作他用，請用「刪除」。已停用的人也能在「已停用的人員」那列按「編輯」，再按左下角「刪除」。

7 角色與權限

這頁決定每個角色能做哪些事，也可以建立「客服組長」「行銷專員」這類自訂角色。預設只有管理員看得到這頁。

查看或調整角色權限

  1. 到「設定 → 角色與權限」，在左邊點一個角色。
  2. 右邊依「客服作業」「案件」「聯絡人」等功能分組列出權限。打勾代表有這項權限。
  3. 權限很多時，可以在「搜尋權限…」輸入關鍵字，或按「只看已開」「只看未開」篩選。
  4. 勾選或取消後，頁面底部會出現「未儲存 N 項變更」。按「儲存變更」生效；改錯了按「放棄」。
  • 有些權限要先有另一項才能用，例如要「回覆對話」得先能「檢視對話」。你勾後面那項，前面那項會自動勾起來，並標示「自動開啟」。
  • Admin 角色有幾項標「內建鎖定」的權限不能取消，避免公司沒有人能管理帳號。
  • 每項權限旁邊會顯示一小段英文代碼與說明，那是給技術人員對照用的，看中文名稱就好。

建立自訂角色

  1. 按左側最下方「＋ 新增角色」。
  2. 在「角色名稱」輸入名稱（最多 20 字，例如「客服組長」），按「建立並設定權限」。
  3. 新角色一開始什麼權限都沒有。在右邊勾選它可用的權限，按「儲存變更」。
  4. 回到「人員管理」，編輯成員，在「角色」選這個新角色（會顯示為「名稱（自訂）」）。

自訂角色可以改名或刪除：把滑鼠移到左邊的自訂角色上，會出現鉛筆（改名）和垃圾桶（刪除）圖示。

ℹ️
還有人使用中的角色不能刪除。這時刪除視窗會列出還在用這個角色的成員姓名，已停用的人會標「（已停用）」。請先到「人員管理」把他們改成其他角色（已停用的人在「已停用的人員」區塊按「編輯」處理，見第 6 節），再回來刪除。
ℹ️
「系統設定」這一項權限一次涵蓋營業時間、追蹤設定、跨渠道綁定、API 金鑰、CLI 連線、方案與帳務等好幾頁，沒辦法只開其中一頁。「刪除成員（舊）」是已淘汰的項目，勾不勾都沒有作用。

8 我的帳號與修改密碼

「設定 → 一般設定」是你自己的帳號頁，每個人都能用。上方「個人資料」顯示你的姓名、電子信箱與角色，這些由管理員維護，自己不能改；下方可以修改自己的登入密碼。

  1. 到「設定 → 一般設定」。
  2. 在「修改密碼」填「目前密碼」。
  3. 填「新密碼」和「確認新密碼」，兩次要一樣，而且至少 8 個字、不能跟目前密碼相同。欄位右邊的眼睛圖示可以顯示或隱藏你打的字。
  4. 按「更新密碼」，按鈕變成「密碼已更新」就完成了。
ℹ️
新密碼欄位的提示文字寫「至少 6 個字元」，實際上要 8 個字以上。角色欄目前會顯示英文（例如 ADMIN），不會顯示自訂角色名稱。
⚠️
如果懷疑帳號被別人登入，改密碼不會把其他電腦上已登入的人登出。請同時通知管理員處理。

人員管理頁右上角的「修改密碼」按鈕也能改自己的密碼，但那裡沒有「確認新密碼」欄，建議用一般設定這頁比較不會打錯。忘記自己的密碼時，請管理員用編輯人員的「重設密碼」幫你設一組新的。

9 Passkey 免密碼登入

Passkey 讓你用電腦或手機的 Touch ID、Face ID、Windows Hello 或裝置 PIN 碼登入，不用每次輸入密碼。每個人只能管理自己的 Passkey。

綁定這台裝置

  1. 用你平常登入的那台電腦或手機，到「設定 → Passkey 登入」。
  2. 按「綁定 Passkey」。
  3. 在「裝置名稱」取一個好認的名字，例如「公司筆電」「我的 iPhone」（最多 80 字），按「繼續綁定」。
  4. 電腦或手機會跳出指紋、臉部或 PIN 碼驗證，照指示完成。
  5. 完成後，這台裝置會出現在「已綁定的裝置」清單。

用 Passkey 登入

登入頁會多一個「使用 Passkey 登入」按鈕。按下去後完成裝置驗證，就能直接進入系統。

管理已綁定的裝置

  • 「同步式 Passkey」會透過 Apple、Google 等帳號同步到你的其他裝置；「單一裝置 Passkey」只存在那一台。「已備份」表示有雲端備份，換手機也不會遺失。
  • 鉛筆圖示：改裝置名稱。
  • 垃圾桶圖示：撤銷。電腦遺失或不再使用時請撤銷，撤銷後那台裝置就不能再用 Passkey 登入。
ℹ️
如果「綁定 Passkey」按鈕是灰色的，並出現「Passkey 尚未啟用…」的提示，代表系統還沒開放這個功能，請聯絡系統維運人員。綁定時如果你在驗證視窗按了取消，對話框會停在原地、看不到錯誤訊息，按「取消」關掉重來即可。
