## Writing rules for documents

When you write or change text in this repo, apply the writing skill for its language before you
finish. Apply it also when you change only some sentences of a document.

| Language | Skill |
| -------- | ----- |
| Traditional Chinese | `simplified-technical-chinese` |
| English | `asd-ste100` |

The "Writing rules for documents" item in the Conventions section of `AGENTS.md` tells which
text these rules apply to.
